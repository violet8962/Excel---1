# 第二章实验说明 · 30 例基础图表

> 源文件：`第二章 图表(前15).xlsx`、`第二章 图表(后15).xlsx`
> 代码：`src/excel_viz/ch2_part1.py`（01~15）、`src/excel_viz/ch2_part2.py`（16~30）
> 输出：`output/ch2/01_*.png ~ 30_*.png`

## 实验目的

原书第二章用 30 个案例讲解图表的「建立—修饰」流程。本实验把这 30 例全部
迁移到 Python，验证两个问题：

1. Excel 里靠**辅助占位序列 + 形状叠加**做出来的装饰性图表，Python 里能否用
   更直接的绘图原语实现；
2. 原书强调的修饰规范（三步法）能否沉淀成可复用代码。

## 实验步骤

1. `python scripts/extract_source_data.py` —— 从两个源工作簿抽取 30 张小表；
2. 逐例阅读原表数据结构（大多数是「维度 + 度量值 + 占位列」三段式）；
3. 识别每例在 Excel 里的实现机关（占位列、形状、渐变、圆角、数据标记等）；
4. 用 matplotlib 等价原语重写，每例一个独立函数，返回输出路径；
5. `python scripts/run_all.py --only ch2` 批量出图，与原书逐图对照。

## 关键迁移点

| Excel 机关 | Python 等价实现 |
|---|---|
| 渐变填充柱形 | 柱形透明 + `imshow` 渐变图 + `set_clip_path` |
| 圆角柱形（形状填充） | `FancyBboxPatch(boxstyle="round")` |
| 占位列撑出蝴蝶图中缝 | 正负双向 `barh`，直接省掉占位列 |
| 平滑线选项 | Catmull-Rom 样条（`utils.catmull_rom`） |
| 垂直线元素 | `utils.drop_lines` |
| 圆环图占位凑缺口 | 直接控制 `Wedge` 起止角 |
| 水球（圆 + 形状裁剪） | `Rectangle` + `Circle` 裁剪 |
| 仪表盘（饼图拼装） | 三段 `Wedge` 刻度盘 + `annotate` 指针 |
| 次坐标轴组合图 | `twinx()` |
| 数据标签 / 引线 | `ax.text` / `ax.annotate` |

## 结论

- Excel 的「占位序列」本质是绘图坐标的补数运算，Python 中可以直接用坐标表达，
  30 例中有 8 例因此实现代码显著缩短；
- 装饰性图表（水球、跑道、玉玦、玫瑰）在 Python 中无需形状拼装，一个循环即可；
- 真正需要「设计感」的只剩配色与留白，已统一沉淀到 `theme.py`。
