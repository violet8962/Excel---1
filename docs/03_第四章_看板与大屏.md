# 第四章实验说明 · 可视化看板与数据大屏

> 源文件：`第四章 人力资源可视化看板.xlsx`、`第四章 销售看板参考.xlsx`
> 代码：`src/excel_viz/ch4_dashboard.py`
> 输出：`output/ch4/人力资源可视化看板.png`、`output/ch4/销售数据大屏.png`

## 实验目的

看板 = 多图表 + 统一修饰 + 有主次的排版。Excel 里靠「隐藏网格线、形状打底、
逐图对齐」手工拼装；Python 里用 `GridSpec` 一次成型，且所有指标由明细数据
实时聚合，**换数据即可复用**。

## 一、人力资源可视化看板（浅色）

- 数据：2022 年 3 月人员基础信息 1,470 人（员工编号已脱敏）；
- KPI 卡片：总人数 / 平均年龄 / 本月入职 / 男女比；
- 图表：年龄结构、婚姻状况、性别结构（圆环）；部门、学历、本月入转调（条形）；
- 排版：`GridSpec(3, 6)`，上排 KPI，中排三个圆环，下排三个条形。

## 二、销售数据大屏（深色）

- 数据：销售明细 8,564 条订单 + 成本明细 48 行（订单号已脱敏）；
- KPI：销售额 1,515.4 万 / 利润额 154.9 万 / 利润率 10.2% / 订单数 8,564；
- 图表：各月销售额（面积）、订单量环比（正负柱）、利润率（半环仪表）、
  快递公司销量、区域销售额、产品类别销量（圆环）、商品销售额 Top3；
- 排版：`GridSpec(4, 12)`，顶部标题条 + KPI 行，中部趋势区，下部分布区；
- 深色主题：`theme.DARK_BG / DARK_PANEL / DARK_ACCENT` 统一底色与强调色。

## 三、实验步骤

1. `data.py` 中定义 `hr_summary()` / `sales_summary()`，把看板所需的全部
   汇总指标收敛成两个纯函数；
2. 编写浅色 / 深色两套面板绘制助手（`_panel` / `_dark_ax`、`_donut` / `_dark_donut`）；
3. GridSpec 布局拼装，KPI 卡片用带色条的矩形 + 文本实现；
4. 运行 `python scripts/run_all.py --only ch4` 输出成品。

## 四、结论

- Excel 大屏的工作量主要在「对齐与配色」，Python 用布局器 + 主题常量消掉了
  这部分重复劳动；
- 大屏的每个面板都是普通函数，可单独拆出去做小型报告图；
- 明细驱动（而非手工汇总）保证看板口径一致，环比、利润率等衍生指标自动重算。
