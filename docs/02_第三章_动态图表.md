# 第三章实验说明 · 动态图表

> 源文件：`第三章 动态图表.xlsm`（含宏与表单控件）
> 代码：`src/excel_viz/ch3_dynamic.py`
> 输出：`output/ch3/01_动态柱形图.gif` 等 7 个 GIF，以及 `output/ch3/frames/` 各档位静态帧

## 实验目的

原书第三章的「动态」来自 Excel 的三类机关：

1. **表单控件**（组合框 / 滚动条 / 复选框）把用户选择写进单元格；
2. **查找类函数**（INDEX / VLOOKUP / OFFSET / IF）按控件值重新组织图表数据源；
3. **VBA 宏**直接改数据源。

本实验验证：把「控件当前值」变成 Python 的循环变量，即可无损复现动态效果。

## 实验步骤

1. 抽取 7 张动态图表的数据源与控件说明；
2. 对每个控件档位（月份 / 周期 / 系列组合）重绘一帧；
3. 用 Pillow 将多帧合成 GIF，并把各帧另存为 PNG；
4. 「透视表切片器」一例改用 pandas：`groupby("学历")["月收入"].mean()`，
   再按部门逐帧切换，等价于「透视表 + 部门切片器」联动。

## 逐例对照

| 例 | Excel 机关 | Python 实现 |
|---|---|---|
| 1 动态柱形图 | 组合框 + INDEX + VLOOKUP | 按 k 取第 k 月一行数据 |
| 2 动态跑道图 | 滚动条 + 占位列 | 逐月排序 + 嵌套 Wedge |
| 3 动态南丁格尔圆环图 | 组合框切换周期 | 逐周期重绘玫瑰 |
| 4 动态组合图 | 复选框 + `IF(cond, val, -100)` 隐藏 | 用显隐标志直接控制绘制 |
| 5 透视表切片器 | 透视表 + 切片器 | pandas 透视 + 逐部门帧 |
| 6 VBA 动态玉玦图 | VBA 换数据源 | 循环周期重绘 |
| 7 动态滑珠图 | 滚动条选月份 | 逐月滑珠落位 |

## 结论

- Excel 动态图的本质是「数据源随参数重组」，Python 用函数参数即可表达，
  且 GIF 成品可直接嵌入网页与报告，分享成本低于交互式工作簿；
- 若需要真正的鼠标交互（而非动画回放），把循环变量换成
  `matplotlib.widgets.Slider / RadioButtons` 即可，数据与绘图函数完全复用。
